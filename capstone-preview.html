Annotated Bibliography

Map Creation

This category includes videos and documentation for Godot game engine to create tilemap layers, ordering, scene transitions and collisions. This includes creating the map background itself, organizing the assets, and creating the scenes with collisions.

  • Jackie Codes. "Godot 4 TileMap Tutorial Ep 1 | Setup, Layers, Animation." YouTube, 8 June 2023, www.youtube.com/watch?v=G6TC6ukmSc4.
  • PlayWithFurcifer. "How to Use the New TileMap in Godot 4." YouTube, 13 Feb. 2022, www.youtube.com/watch?v=tQSL2scuqeU.
  • DevWorm. "The SIMPLEST WAY to Change Scenes in Godot." YouTube, 4 June 2022, www.youtube.com/watch?v=FuIn_1aK7rM.
  • "Using TileSets." Godot Engine Documentation, docs.godotengine.org/en/stable/tutorials/2d/using_tilesets.html.
  • "Using TileMaps." Godot Engine Documentation, 2025, docs.godotengine.org/en/stable/tutorials/2d/using_tilemaps.html.
  • "TileMapLayer." Godot Engine Documentation, 2025, docs.godotengine.org/en/stable/classes/class_tilemaplayer.html.
  • Chris' Tutorials. "How to Add Tilemap Collisions in Godot 4." YouTube, 28 June 2022, www.youtube.com/watch?v=1Uk1yhGtnOo.

Character Creation

These resources helped in asset creations, specifically for characters and NPCs in our game. The tutorials range from creating sprite nodes to creating animations and scripts to add movement for sprites.

  • "How to Use an Animated Sprite in Godot." YouTube, www.youtube.com/shorts/lWCGYoAOmJQ.
  • swydev. "MASTER 2D Movement in Godot - Everything You Need to Know." YouTube, 26 July 2024, www.youtube.com/watch?v=RDT5hfYWCrQ.
  • "2D Sprite Animation." Godot Engine Documentation, docs.godotengine.org/en/stable/tutorials/2d/2d_sprite_animation.html.

UI

These tutorials helped with creating the UI. They cover creating and manipulating nodes to allow for user input while also covering how to align and transform them to make them more aesthetically pleasing.

  • 16BitDev. "Drag and Drop Godot 4." YouTube, 25 July 2023, www.youtube.com/watch?v=8cV-5ByZLO.
  • Bramwell. "Smooth Drag N Drop: Godot Guide." YouTube, 30 June 2020, www.youtube.com/watch?v=iSpWZzL2i1o.
  • Octodemy. "Making a GOOD Drag and Drop Inventory." YouTube, 29 July 2025, www.youtube.com/watch?v=JUR1qQ79eJY.
  • IcyEngine. "Godot Programming UI Tutorial - MUST-HAVE Basics!" YouTube, 6 Mar. 2025, www.youtube.com/watch?v=vQFGSz_IeGs.
  • Godotneers. "Godot UI Basics - How to Build Beautiful Interfaces That Work Everywhere (Beginners)." YouTube, 1 Sept. 2023, www.youtube.com/watch?v=1_OFJLyqlXI.
  • Karto. "Godot Control Node (UI) Masterclass." YouTube, 28 Aug. 2024, www.youtube.com/watch?v=5Hog6a0EYa0.

Backend/Scripts

These tutorials introduced us to the key components of script creation. Scripts are what powered the assets to perform their respective tasks via code. We used resources for tasks such as allowing the player to input text and movement, creating instances of assets, and sending signals from one sprite to another.

  • "Creating Your First Script." Godot Engine Documentation, 2025, docs.godotengine.org/en/stable/getting_started/step_by_step/scripting_first_script.html.
  • "Listening to Player Input." Godot Engine Documentation, 2026, docs.godotengine.org/en/stable/getting_started/step_by_step/scripting_player_input.html.
  • "Signals." Godot Engine Documentation, docs.godotengine.org/en/stable/getting_started/step_by_step/signals.html.
  • "Creating Instances." Godot Engine Documentation, 2024, docs.godotengine.org/en/stable/getting_started/step_by_step/instancing.html.
